Refonte & Migration Web — Auto-école Michelet

Conversion complète du site web de l'auto-école Michelet Montauban vers une architecture et un langage informatique plus récents.

PHP JavaScript HTML5 CSS3 SQL Git
Visiter le site web ↗

Contexte du projet

Projet informatique réalisé pour l'Auto-école Michelet à Montauban afin de remplacer une base technique vieillissante.

Objectifs & Fonctionnalités

  • Auditer l'ancien site web et recenser l'ensemble des pages, formulaires et contenus existants.
  • Migrer le code vers une architecture moderne, plus sécurisée et plus facile à maintenir.
  • Améliorer l'ergonomie, les temps de chargement et l'affichage sur smartphones.

Choix Techniques & Architecture

  • Séparation claire entre la logique serveur, l'accès aux données et les vues HTML/CSS.
  • Refonte complète des feuilles de style pour un rendu moderne et adaptable à toutes les tailles d'écran.
  • Documentation technique livrée pour faciliter les futures interventions.

Apports & Compétences mobilisées

J'ai acquis une méthodologie rigoureuse de migration de code existant (analyse de l'existant, iso-fonctionnalité, tests de non-régression).
