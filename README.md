# Portfolio — Vincent Gautier

Site portfolio statique prêt pour **GitHub Pages**, généré à partir de mon CV.

## Déploiement sur GitHub Pages

1. Créez un dépôt sur GitHub (par exemple `vincent-gautier.github.io` ou `portfolio`).
2. Uploadez les fichiers `index.html`, `style.css` et `script.js` à la racine du dépôt.
3. Allez dans **Settings > Pages**.
4. Dans **Source**, sélectionnez **Deploy from a branch**, choisissez la branche `main` et le dossier `/ (root)`, puis cliquez sur **Save**.
5. Votre site sera en ligne quelques instants plus tard !

## Personnalisation
- Pensez à mettre à jour votre adresse e-mail et votre lien GitHub dans la section `#contact` de `index.html`.
- Vous pouvez également ajouter votre photo de profil (`avatar.jpg`) dans la section Hero si vous le souhaitez.
